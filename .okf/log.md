## 2026-09-18
* **Revision**: [integrated-circuits](/integrated-circuits.md) — the catalog is `conjure()` over the per-chip `circuits.<slug>` config each chip package ships and publishes. It reads `default_config` or a named config, and calls the chip's own public static factory with that config's keys as named arguments; the factory is named after the config unless the entry sets `protocol`. Undeclared keys drop, a missing required parameter errors by name, `addCircuit()` skips a non-`IntegratedCircuit` class rather than taking the boot down.
* **Removal**: the 0.7-shaped catalog that had been ported in — `PendingCircuit`, `CircuitTransport`, `CircuitConsoleCommand`, the `#[IntegratedCircuit]` / `#[Pinout]` attributes, `CircuitAttributeInspector`, `CircuitProfileWriter`, `CircuitProfileParamPrompter`, `circuit:make-profile`, and the single root `config/circuits.php`. The wiring already lived in the chip packages' configs; nothing needed scaffolding.
* **Proof**: an ST7789 over an FT232H conjured from `config/circuits/st7789.php` and drew on the bench through Surface's `EmbeddedDisplay::panel('st7789')`. Suite: 168 passed.

## 2026-09-16
* **Revision**: [dock-resource.md](/dock-resource.md) — resource ported onto the connection layer: `DigitalInputTransport` is the `EdgeSource`, `UARTTransport` the `ByteSource`; `DigitalIOConnectionDriver::input()` binds the device so edge mail is `gpio.edge.<device>.<offset>` (the posix/MPSSE offset collision closed).
