# Components

Fabricate components live under `src/Fabricate/*` and are documented here. Each may ship as `fabricate/*` and is `replace`d by the umbrella. PHP namespaces vary by component; several support components currently declare types under `Fabricate\NutsAndBolts\` via multi-path PSR-4 — that is packaging, not a separate product tier.

* [nuts-and-bolts](nuts-and-bolts.md) - Contracts + ScrapyardIOException. (`stable`)
* [collections](collections.md) - Eager/lazy enumerables, Arr, helpers. (`stable`)
* [conditionable](conditionable.md) - `when` / `unless`. (`stable`)
* [macroable](macroable.md) - Runtime macros / mixins. (`stable`)
* [reflection](reflection.md) - Reflector, ReflectsClosures, `lazy()`. (`stable`)
* [chassis](chassis.md) - PSR-11 + ArrayAccess service container. (`stable`)
* [config](config.md) - Configuration Repository. (`stable`)
* [contracts](contracts.md) - Public swap surfaces (`ServiceContainer`, `CLIKernel`, …). (`stable`)
* [core](core.md) - Machine, AssemblyLine, ConsoleKernel → Workshop. (`stable`)
* [console](console.md) - Workshop CLI + scheduling. (`stable`)
* [filesystem](filesystem.md) - Native Filesystem + Flysystem. (`stable`)
* [events](events.md) - Sync Dispatcher. (`stable`)
* [log](log.md) - LogManager / Monolog. (`stable`)
* [cache](cache.md) - CacheManager; file+redis public stores. (`stable`)
* [redis](redis.md) - RedisManager. (`draft`)
* [encryption](encryption.md) - Encrypter encrypt/decrypt; Core Crypt + EncryptionServiceProvider. (`stable`)
* [process](process.md) - Process Factory; Core Process MagicAlias + ProcessServiceProvider. (`stable`)
* [pipeline](pipeline.md) - Onion pipes + Hub; Core Pipeline MagicAlias + PipelineServiceProvider. (`stable`)
* [concurrency](concurrency.md) - sync/process/fork/fiber/pokio drivers. (`stable`)
* [sketches](sketches.md) - Runner + middleware + Flow + AsyncNode. (`stable`)
* [bus](bus.md) - Dispatcher; Core Bus MagicAlias + BusServiceProvider. (`stable`)
* [queue](queue.md) - QueueManager; public sync/redis/database; Core Queue MagicAlias + QueueServiceProvider. (`stable`)
* [database](database.md) - SQL sqlite/mysql/pgsql; Core DB glue. (`stable`)
* [polisher](polisher.md) - SQL Polisher under Database. (`stable`)
* [graph](graph.md) - Optional Neo4j companion; Graph Polisher. (`stable`)
* [http](http.md) - Outbound HTTP client; Core Http glue. (`stable`)
* [hashing](hashing.md) - HashManager bcrypt/argon; Core Hash + HashServiceProvider. (`stable`)
